# 투자비 대시보드 프로젝트 개요 및 적용 계획

## 1. 주요 활용 기술 및 도구

- 데이터 수집/전처리: Excel 파일 업로드, `xlsx` 기반 워크북 파싱, 투자오더번호 매핑, 월별 투자비 집계
- 투자비 정합성 검증: `C14` 월별 실적투자비 검증, `C15~C108` 상세행 합계 검증, 복수 투자오더·복수 파일 합산, 음수 환입·조정 금액 처리
- 프론트엔드 개발: React, TypeScript, Vite, React Router
- 데이터 저장/인증: Supabase Auth, Supabase Database, Row Level Security(RLS), Supabase 기반 클라우드 동기화
- 대시보드 시각화: 소재별 도넛 차트, 사업별 투자비 바 차트, Rolling Plan 분기·월별 비교, 반응형 테이블
- 업무 권한 관리: 임원·직책자 조회 권한, 실무담당자 입력 권한, 관리자 전체 관리 권한
- 일정 관리: 사업승인, 토건착공, 기전착공, 준공(시운전완료), SOP의 계획·실적일 및 단축·지연 사유 관리
- 생성형 AI/LLM 활용: 자연어 기반 투자비·일정 분석 Agent, 승인 문서 기반 안전규정 RAG, 구조화된 Tool 결과를 자연어로 요약하는 Agent Gateway
- AI 업무 Tool: 투자비 이상 탐지, 계획 대비 실적 차이 설명, 임원용 브리핑, 누락 데이터 탐지, 엑셀 정합성 검증
- AI 서비스 보안: 역할 기반 Tool 접근 제어, 허용 Tool 목록, 근거 없는 안전규정 답변 차단, 조회 전용 운영 경계
- 배포/협업: GitHub, Vercel, 별도 API Server 구조, Pull Request 및 커밋 기반 배포
- 테스트/품질관리: Vitest, React Testing Library, TypeScript 타입 검사, Vite 프로덕션 빌드, Agent 권한·정합성 테스트
- MCP 확장 설계: MCP Host·MCP Client·Horizon MCP Server 분리 구조를 설계했으나, 현재는 테스트·설계 단계이며 실제 적용하지 않음

## 2. 코멘트

기존에 분산되어 있던 투자사업 일정 관리, 복수 투자오더 기반 투자비 집계, Excel 정합성 검증, 경영진용 대시보드 조회를 하나의 웹앱으로 통합한 프로젝트입니다.

특히 사업별 투자오더가 여러 개일 수 있다는 업무 특성을 반영해 동일 사업의 월별 투자비를 합산하고, `C14`와 `C15~C108`의 금액 정합성을 검증하도록 설계했습니다. 단순한 차트 화면이 아니라 데이터 입력·검증·권한·클라우드 동기화까지 포함한 사내용 업무 시스템을 목표로 했습니다.

또한 안전규정 RAG와 자연어 분석 Agent를 추가해 사용자가 별도 시스템을 이동하지 않고 투자비·일정·안전규정을 질문할 수 있는 기반을 마련했습니다. 다만 실제 사내 LLM과 MCP Server를 연결하는 부분은 향후 확장 과제로 남겨두었습니다.

## 3. 단기 적용 계획

- Vercel 배포 환경에서 Supabase Auth, RLS, `/api/agent` 실제 호출을 통합 검증

- 운영 데이터 기준으로 사업·투자오더 매핑 및 Excel 업로드 검증 시나리오 재검증

- 임원·실무담당자·관리자 계정별 대시보드, 사업관리, 투자비 가져오기 권한 점검

- 투자비 이상 탐지 결과와 계획 대비 실적 차이 설명을 실제 경영진 질문 시나리오로 검증

- 안전규정 RAG의 승인 문서·출처·페이지 인용 품질 점검 및 사내 공식문서로 교체

- Agent의 조회 전용 운영 상태를 유지하고, 저장·확정 기능은 승인·원자성·감사로그 검토 후 별도 적용

- 모바일 화면과 작은 해상도에서 대시보드 차트·사업목록·Agent 패널의 가독성 점검

## 4. 장기 적용 계획

- 사내 시스템과 연동해 투자오더번호별 투자비를 자동 수집하고 월별 누적투자비를 자동 반영

- 사내 LLM 또는 OpenAI-compatible 사내 모델을 연결해 투자비·일정 데이터의 외부 전송을 최소화

- MCP Host와 MCP Client를 대시보드에 통합하고, 별도 MCP Server를 Horizon에 배포하는 확장 구조 적용

- 투자비·일정·엑셀·안전규정 Tool을 MCP 표준 기반으로 모듈화하고 사내 업무 Tool을 단계적으로 추가

- 사용자 확인 기반의 작업 초안 저장, 승인 workflow, 원자적 데이터 저장, 감사로그를 운영 수준으로 구현

- Rolling Plan 변경 이력, 투자비 추세, 연말 집행 예측 및 일정 지연 위험 분석 기능 고도화

- 사업 수가 증가해도 소재별 사업현황·사업목록·투자비 차트가 자동으로 확장되는 데이터 중심 구조 완성

- 여러 사업장과 추가 투자사업을 지원하는 전사 투자비 통합 플랫폼으로 확장

## 6. 전체 프로젝트 개요와 프로젝트 간단 보고서

### 6-1. 전체 프로젝트 개요

본 프로젝트는 경영진·임원에게는 조회 중심의 투자비 현황을 제공하고, 실무담당자와 관리자에게는 사업 일정·투자비·Rolling Plan을 입력·검증·관리할 수 있도록 구성한 사내용 투자비 관리 웹앱입니다.

주요 화면은 로그인, 대시보드, 사업목록, 사업 상세, 사업관리, 투자비 가져오기, 안전규정으로 구성됩니다.

대시보드에서는 양극재·음극재 사업을 소재별 도넛 차트로 구분하고, 우측에는 사업별 승인투자비·누적투자비·누적률을 바 차트로 표시합니다. 하단 사업목록에서는 각 사업의 일정 계획·실적, 단축·지연 사유, 투자비 현황을 한 화면에서 확인할 수 있습니다.

사업 상세 화면에서는 사업 기본정보, 승인투자비·누적투자비·집행률, 주요 일정, 분기별 Rolling Plan과 당해년도 월별 비교를 제공합니다.

### 6-2. 투자비 데이터 처리 흐름

```text
Excel 파일 업로드
   ↓
투자오더번호 확인
   ↓
사업별 투자오더 매핑
   ↓
C14 월별 실적투자비 추출
   ↓
C15~C108 상세행 합계 검증
   ↓
동일 사업·월·복수 투자오더 합산
   ↓
월별 실적 누적
   ↓
누적투자비·집행률 계산
   ↓
대시보드 반영
```

### 6-3. AI Agent 개요

현재 AI Agent는 다음 기능을 중심으로 구현되어 있습니다.

- 투자비 이상 탐지
- 계획 대비 실적 차이 설명
- 임원용 핵심 브리핑
- 사업·일정·투자오더 누락 탐지
- Excel 투자비 정합성 검증
- 승인된 안전문서 기반 자연어 질의응답

AI는 금액이나 일정을 임의로 변경하지 않으며, 서버 측 Tool과 검증 결과를 기반으로 답변합니다. 실제 저장·확정 작업은 운영 검증이 끝난 후 별도의 승인·감사 workflow로 확장할 예정입니다.

### 6-4. 권한 및 운영 모델

- 임원·직책자: 대시보드와 Agent 조회·분석
- 실무담당자: 사업 일정, 실적, 사유, 승인투자비, Rolling Plan 입력·수정 및 투자비 검증
- 관리자: 사업·권한·투자비·일정 전체 관리

모든 투자비와 일정 데이터는 Supabase 기반 클라우드 저장을 목표로 하며, 권한은 Supabase Auth와 RLS를 통해 통제합니다.

### 6-5. 프로젝트 간단 보고서

이 프로젝트는 기존의 수기·분산 관리 방식으로 발생하던 투자비 집계 오류와 일정 현황 확인의 불편을 개선하기 위해 개발되었습니다. 특히 하나의 투자사업에 복수 투자오더가 존재할 수 있고, 월별 Excel 자료가 반복 업로드된다는 실제 업무 특성을 반영했습니다.

프로토타입 단계에서는 담당자가 Excel을 업로드하고 투자오더를 사업에 매핑하면, 시스템이 월별 실적투자비를 합산하고 누적투자비와 집행률을 계산합니다. 또한 `C14` 총액과 `C15~C108` 상세 금액을 비교해 업로드 자료의 정합성을 확인합니다.

화면 측면에서는 임원용 대시보드와 실무자용 관리 화면을 분리하고, 사업 추가·수정·활성화, 일정 계획·실적 및 사유 입력, Rolling Plan 관리 기능을 제공하도록 구성했습니다. 이후 안전규정 RAG와 AI Agent를 연결하여 투자비와 일정 데이터를 자연어로 분석할 수 있는 기반도 추가했습니다.

최종 목표는 회사 내부 시스템에서 투자오더별 투자비를 자동 수집하고, 사내 LLM과 MCP 기반 업무 Tool을 통해 경영진에게는 신뢰도 높은 요약을, 실무자에게는 정합성 검증과 입력 보조를 제공하는 전사 투자비 관리 플랫폼으로 확장하는 것입니다.

# 대시보드 레이아웃 및 툴팁 개선 설계

## 목표

대시보드의 소재별 도넛 차트, 사업별 투자비 바 차트, 사업목록 표, 실적 사유 표시를 한 화면에서 안정적으로 읽을 수 있도록 개선한다.

## 변경 설계

### 소재별 사업현황

- 도넛 차트 SVG/요소와 hover 상세목록을 별도 레이어로 유지한다.
- 상세목록은 좌측 차트 패널 내부에서만 렌더링하며 우측 바 차트 영역으로 확장하지 않는다.
- hover 중에도 도넛의 원형 마스크와 중앙 구멍은 유지한다.

### 사업별 투자비 현황

- 각 사업의 트랙 안에서 누적투자비를 상단, 승인투자비를 하단에 배치한다.
- 값 표시와 범례의 순서도 누적투자비 → 승인투자비로 맞춘다.

### 사업목록 표

- 표 레이아웃을 고정 테이블로 전환하고 열 너비를 명시한다.
- 투자비 현황 열은 제한된 폭으로 줄이고 금액은 줄바꿈 가능한 형태로 표시한다.
- 헤더와 데이터 셀을 가로·세로 중앙 정렬하며 행 높이와 패딩을 균일하게 적용한다.

### 실적 사유

- 실적 날짜에 사유가 있을 때만 hover 상호작용과 설명 표시를 활성화한다.
- 사유가 있는 날짜를 hover하면 표 아래 고정 설명박스에 사유를 표시한다.
- 사유가 비어 있으면 hover 표식과 설명박스를 렌더링하지 않는다.
- 설명박스는 표의 가용 너비 안에서 잘리지 않도록 배치한다.

## 검증

- 기존 단위/통합 테스트를 통과해야 한다.
- 프로덕션 빌드가 성공해야 한다.
- 대시보드에서 도넛 hover, 바 차트 순서, 표 정렬·폭, 사유 있음/없음 상태를 확인한다.

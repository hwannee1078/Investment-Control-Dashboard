# Rolling Plan 연도·분기 보기 설계

## 목표
- 사업 상세에서 중복된 월별 투자비 펼치기 영역을 제거한다.
- Rolling Plan을 연도별 4개 분기 합계 그래프로 먼저 보여준다.
- 시스템 현재 연도만 분기 선택 시 3개월 상세 그래프를 활성화한다.

## 동작
- `rollingPlan`의 월별 계획과 투자비 실적을 연도·분기 단위로 합산한다.
- 현재 연도는 1~4분기 카드 클릭 시 해당 분기의 3개월 계획·실적 막대와 차이 사유를 표시한다.
- 현재 연도가 아닌 연도는 분기 합계만 표시하며 월별 상세를 열 수 없다.
- 데이터가 있는 연도만 표시하고, 월별 데이터가 없는 분기는 0으로 표시한다.

## 검증
- 월별 투자비 펼치기 버튼과 영역이 상세 화면에서 사라진다.
- 현재 연도 판정이 시스템 날짜의 연도와 일치한다.
- 분기 합계와 월별 상세 합계가 일치한다.

# 안전규정 RAG 챗봇 설계

## 목표

투자비 대시보드에 `안전규정` 탭을 추가하고, 공식 법령·정부 지침·KOSHA 자료·승인된 사내 문서를 기반으로 안전 관련 질문에 근거와 출처를 함께 답변하는 문서 기반 RAG 기능을 제공한다.

## 적용 범위

### 외부 공식자료

1. 국가법령정보센터
   - 산업안전보건법, 시행령, 시행규칙
   - 중대재해 처벌 등에 관한 법률 및 시행령
   - 산업안전·화학물질·위험성평가 관련 법령
   - 법령명, 조문 번호, 시행일, 개정일, 원문 URL 저장
2. 고용노동부
   - 산업안전보건 관련 훈령·예규·고시
   - 행정해석, 질의회시, 안전보건 지침
3. 한국산업안전보건공단(KOSHA)
   - KOSHA Guide
   - 공정·설비·화학물질·위험성평가 안전자료
   - 교육자료와 실무 지침

### 사내자료

- 안전보건 규정, 작업표준서, 공정별 안전절차
- 내부 위험성평가 기준과 사고사례·재발방지대책
- 관리자 업로드 후 승인된 문서만 검색 대상으로 포함

## 사용자 경험

- 대시보드 메뉴에 `안전규정` 탭 추가
- 질문 입력 후 관련 근거 문서와 함께 답변 표시
- 답변마다 문서명, 조문·페이지·항목, 시행일 또는 게시일, 원문 링크, 기준일 표시
- 근거가 부족하면 추측하지 않고 “확인 가능한 공식 근거가 없습니다”라고 표시
- 모든 답변에 참고용 정보이며 최종 판단은 안전·법무 담당자 확인이 필요하다는 안내 표시

## 권한

- 임원·직책자·일반 조회자: 승인된 문서 검색과 챗봇 조회만 가능
- 실무담당자: 승인된 사내자료 검색, 문서 업로드 요청 가능
- 관리자: 문서 업로드·삭제·승인·재색인, 공식자료 수집 상태와 오류 확인 가능
- 승인되지 않은 문서는 어떤 역할에도 RAG 검색 결과로 노출하지 않음

## 데이터 흐름

1. 관리자가 문서를 업로드하거나 공식자료 수집 작업이 새 버전을 발견한다.
2. 원본 파일과 메타데이터를 Supabase Storage에 저장한다.
3. 문서를 제목·조항·페이지·단락 단위로 분할한다.
4. 각 조각에 임베딩을 생성하고 Supabase의 벡터 컬럼에 저장한다.
5. 문서 상태를 `대기 → 검토중 → 승인 → 색인완료`로 관리한다.
6. 사용자가 질문하면 질문 임베딩으로 승인된 문서 조각을 검색한다.
7. 검색 결과만 모델에 전달해 답변을 생성한다.
8. 답변과 함께 인용 문서, 기준일, 원문 링크를 반환한다.

## 갱신 정책

- 법령·고시: 매일 변경 여부 확인
- 고용노동부·KOSHA 자료: 주 1회 변경 여부 확인
- 사내자료: 관리자 승인 시 즉시 색인
- 문서 버전과 수집일을 보존하고, 최신 버전과 폐기 버전을 구분
- 최신 시행일이 미래인 법령은 “시행 예정”으로 표시

## 데이터 모델 초안

- `safety_documents`: 문서 기본정보, 출처, 문서종류, 버전, 상태, 시행일, 원문 URL
- `safety_document_chunks`: 문서 조각, 페이지·조항 정보, 임베딩, 검색용 텍스트
- `safety_ingestion_runs`: 수집 실행 이력, 성공·실패 건수, 오류 메시지
- `safety_chat_sessions`: 사용자 질문과 답변 이력
- `safety_citations`: 답변별 인용 문서 조각과 표시 순서

모든 테이블은 기존 Supabase 인증 사용자와 역할 정책을 사용하며, 사내 문서와 대화 이력은 조직 외부에 공개하지 않는다.

## 오류와 안전장치

- 공식 출처가 아닌 검색 결과는 기본 수집 대상에서 제외
- 문서 파싱 실패 시 관리자에게 오류와 파일명을 표시
- 출처 없는 답변 생성 금지
- 법령 개정으로 충돌하는 문서가 있으면 최신 시행일 문서를 우선하고 구버전도 함께 표시
- 고위험 질문에는 안전관리자·법무 담당자 확인 안내를 강조
- 사용자 질문과 문서 내용에 개인정보·비밀정보가 포함되지 않도록 저장·접근 권한 제한

## 단계별 구현

### 1단계: 시연용

- 관리자 문서 업로드
- PDF·DOCX·TXT 중심 텍스트 추출
- 문서 승인과 간단한 검색
- 안전규정 탭의 질문·답변·출처 표시
- 샘플 공식자료와 사내 문서로 검증

### 2단계: 운영 안정화

- 국가법령정보센터·고용노동부·KOSHA 수집 자동화
- 문서 버전 비교와 개정 알림
- 질문 이력·답변 품질 검토
- 관리자용 수집 오류·색인 상태 화면

### 3단계: 사내 시스템 연동

- 사내 문서관리시스템 연동
- SSO·조직별 접근권한 연계
- 안전점검·위험성평가·사업정보와 질문 맥락 연결

## 검증 기준

- 승인된 문서만 검색되는지 확인
- 답변마다 최소 1개 이상의 인용이 표시되는지 확인
- 법령 시행일과 기준일이 표시되는지 확인
- 근거 없는 질문에 추측 답변을 하지 않는지 확인
- 임원·실무자·관리자 권한별 업로드·승인·조회 동작을 확인
- 모바일 화면에서 질문, 답변, 출처 링크를 사용할 수 있는지 확인

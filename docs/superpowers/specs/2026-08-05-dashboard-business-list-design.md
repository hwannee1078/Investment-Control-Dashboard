# 대시보드 사업목록·일정 통합 설계

## 목표

경영진용 대시보드에서 소재별 사업현황을 먼저 보여주고, 사업관리 화면에서 입력한 사업 기본정보와 계획/실적 일정을 같은 페이지의 사업목록으로 조회한다.

## 화면 구성

1. 페이지 상단에 소재별 사업현황 원형테이블을 배치한다.
2. 원형테이블의 기존 hover 사업목록 동작은 유지한다.
3. 승인투자비·누적투자비·집행률 요약 카드는 제거한다.
4. 원형테이블 아래 사업목록을 배치한다.
5. 사업목록은 사업명, 소재지, 사업일정으로 구성한다. 소재와 사업상태 컬럼은 표시하지 않는다.
6. 사업일정은 사업승인, 토건착공, 기전착공, 준공(시운전완료), SOP 각각에 대해 계획일과 실적일을 표시한다.
7. 사업명 클릭 시 기존 사업 상세 페이지로 이동한다.

## 데이터 흐름

사업관리 화면이 저장하는 Project의 기본정보와 schedule을 DashboardPage가 동일한 ProjectRepository에서 조회한다. 일정 표시는 날짜가 있으면 `YYYY.MM.DD`, 없으면 `-`로 표시한다.

## 검증

- 대시보드에서 요약 카드가 렌더링되지 않는다.
- 소재별 원형테이블과 hover 목록이 유지된다.
- 사업목록에 소재·사업상태가 없고, 5개 일정 행과 계획/실적 열이 표시된다.
- 관리 화면에서 수정한 사업명·소재지·일정이 대시보드에 반영된다.

# 투자비 대시보드 AI Agent 설계

## 1. 목표와 범위

기존 투자비 대시보드에 자연어 기반 통합 업무 Agent를 추가한다. Agent는 투자비·일정 분석을 핵심으로 제공하고, 엑셀 투자비 검증과 안전규정 RAG를 전문 도구로 연결한다.

초기 버전은 조회·분석과 작업 초안 생성까지 지원한다. 실제 데이터 변경은 사용자가 초안을 확인하고 저장 버튼을 누른 경우에만 수행한다.

## 2. 사용자와 권한

- 임원·직책자: 대시보드 조회, 투자비·일정 분석, 안전규정 질문
- 실무담당자: 위 기능 + 투자비 반영 초안, 일정·실적·사유 수정 초안 저장
- 관리자: 실무담당자 기능 + 모든 사업·권한·데이터 관리

모든 저장 작업은 기존 역할 검사를 통과해야 한다. Agent는 역할을 우회하거나 Supabase 테이블을 직접 수정하지 않는다.

## 3. 사용자 경험

### 플로팅 Agent

로그인 후 모든 화면 우측 하단에 기존 안전 챗봇을 확장한 Agent를 표시한다. 사용자는 투자비, 일정, 엑셀 검증, 안전규정 질문을 한 대화창에서 입력한다.

답변에는 요약, 수치·일정 근거, 기준일, 관련 사업, 안전문서 인용을 포함한다. 필요하면 상세 화면으로 이동하는 링크를 제공한다.

### 전체 Agent 페이지

`/agent` 경로에서 대화 내역, 추천 질문, 최근 분석, 저장 대기 초안, 업로드 검증 결과, 안전 검색 기록을 확인한다.

### 작업 초안 카드

데이터 변경이 필요한 요청에는 대상 사업, 투자오더, 기준 월, 변경 전·후 값, 검증 결과를 표시한다. 사용자는 `저장하기`, `수정하기`, `취소` 중 하나를 선택한다.

## 4. Agent 오케스트레이션

```text
사용자 질문
  -> 의도 분류
  -> 업무 도구 호출
  -> 계산·권한·정합성 검증
  -> 답변 또는 작업 초안
  -> 사용자 승인
  -> 저장 및 감사로그
```

초기 구현은 도구 호출형 Agent를 사용한다. AI는 판단·요약·초안을 생성하고, 금액 계산·검증·권한 확인은 결정론적인 코드 도구가 담당한다.

## 5. 업무 도구 인터페이스

### 조회 도구

- `getProjectSummary`: 사업별 승인투자비, 누적투자비, 잔여투자비, 누적률 조회
- `comparePlanActual`: Rolling Plan과 월별 실적, 일정 계획·실적 차이 분석
- `getProjectContext`: 사업 기본정보, 활성화 상태, 투자오더 매핑 조회
- `searchSafetyKnowledge`: 승인된 법령·고용노동부·KOSHA·사내 문서 검색

### 계산·검증 도구

- `aggregateInvestmentOrders`: 여러 투자오더의 월별 `C14` 합산 및 누적 계산
- `validateInvestmentWorkbook`: 각 파일의 `C14 = C15~C108` 합계 검증
- `validateImportBatch`: 중복 파일, 누락·미매핑 투자오더, 기준 월 불일치 검증
- `calculateScheduleVariance`: 계획일·실적일 차이와 지연/단축 일수 계산

### 초안 도구

- `prepareInvestmentImport`: 사업별 투자비 반영 초안 생성
- `prepareScheduleUpdate`: 일정, 실적일, 단축·지연 사유 수정 초안 생성

### 저장 도구

저장 도구는 사용자 ID, 역할, 대상 사업, 변경 전·후 값, 사용자 확인 여부를 요구한다. 저장 전 역할과 정합성을 다시 확인하고 성공 또는 실패를 감사로그에 기록한다.

## 6. 투자비 데이터 흐름

1. 사용자가 하나 이상의 Excel 파일을 제출한다.
2. 파일에서 투자오더번호와 기준 월을 식별한다.
3. 등록된 사업·투자오더 매핑을 조회한다.
4. 파일별 `C14`를 계산하고 `C15~C108` 합계와 비교한다.
5. 같은 사업의 여러 투자오더와 파일을 월별로 합산한다.
6. 월별 실적을 누적해 누적투자비를 계산한다.
7. 중복·누락·불일치가 없을 때 반영 초안을 표시한다.
8. 사용자가 승인하면 저장한다.

음수 환입·조정 금액은 유효한 실적으로 허용하되, 설명과 검증 결과에 명시한다.

## 7. 안전 RAG 원칙

- `approved` 상태의 문서와 청크만 검색한다.
- 답변에 문서명, 조항/섹션, 페이지, 출처일, 원문 링크를 포함한다.
- 승인 문서에서 확인되지 않는 질문은 근거 부족으로 안내하고 담당자 확인을 요청한다.
- 안전규정 답변을 투자비·일정 데이터와 혼동하지 않도록 도메인별 도구를 분리한다.

## 8. 오류 처리

다음 조건에서는 저장을 차단한다.

- 투자오더가 사업에 매핑되지 않음
- 동일 파일 또는 동일 월 중복 업로드
- `C14`와 `C15~C108` 합계 불일치
- 여러 파일의 기준 월 불일치
- 권한 없는 사용자의 수정 시도
- 안전문서 근거가 없는 답변 요청

오류 메시지는 원인, 영향을 받는 사업·파일, 해결 방법을 함께 안내한다. 저장 실패 시 기존 데이터는 유지하고 재시도할 수 있어야 한다.

## 9. 감사로그

Agent 작업마다 다음을 기록한다.

- 사용자 사번과 역할
- 자연어 질문
- 호출된 도구와 입력 요약
- 조회·변경 대상
- 변경 전·후 값
- 사용자 승인 여부
- 성공·실패 결과와 오류 내용
- 처리 시각

## 10. 테스트 기준

- 여러 투자오더 합산 결과가 대시보드와 일치한다.
- 월별 실적과 누적투자비, 누적률이 정확하다.
- `C14 = C15~C108` 검증과 음수 조정 금액이 처리된다.
- 중복·누락·미매핑 파일이 저장 전에 차단된다.
- 계획 대비 일정 차이와 사유가 정확히 표시된다.
- 임원은 저장할 수 없고, 실무자·관리자는 권한에 따라 저장할 수 있다.
- 안전 답변은 승인 문서만 인용한다.
- 네트워크·저장 실패 시 기존 데이터가 보존된다.

## 11. 단계적 출시

1. 읽기 전용 투자비·일정 분석 도구
2. 엑셀 검증과 반영 초안
3. 일정 수정 초안
4. 저장 승인과 감사로그
5. gstack 기술·보안·배포 검토 후 운영 반영

## 12. 1차 핵심 분석 도구

초기 Agent에는 다음 5개 도구만 우선 적용한다. 이 범위는 경영진 분석 가치와 실무 검증 효과를 확보하면서 구현·검증 복잡도를 제한한다.

- `findInvestmentAnomalies`: 집행률 급락, 승인투자비 초과, 음수 조정, 전월 대비 급변 탐지
- `explainVariance`: Rolling Plan·월별 실적·일정 계획/실적과 담당자 사유를 근거로 차이 요약
- `getExecutiveBriefing`: 전체 사업의 투자비·일정 핵심 이슈를 짧은 경영진 브리핑으로 생성
- `findMissingData`: 일정, 실적, 사유, 투자오더 매핑 등 필수 데이터 누락 탐지
- `reconcileInvestmentWorkbook`: 업로드 파일의 `C14`와 `C15~C108` 합계를 비교하고 오류 행과 원인을 반환

이 5개 도구는 모두 조회·분석 또는 검증 결과를 반환한다. 데이터 변경은 기존 `prepare...` 초안 도구와 사용자 승인 저장 흐름을 통해서만 수행한다.

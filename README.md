# 투자비 대시보드

사내 투자사업의 일정과 투자비를 조회·관리하는 React 프로토타입입니다.

## 주요 기능

- 소재별 사업현황: 양극재·음극재 도넛 차트와 hover 사업 목록
- 사업별 승인투자비·누적투자비·누적률 바 차트
- 사업목록의 계획·실적 일정과 실적 사유 tooltip
- 사업 추가·수정·활성화·비활성화
- 연도별 Rolling Plan 및 당해년도 분기 월별 상세
- 여러 투자오더·엑셀 파일의 월별 투자비 합산
- C14와 C15:C108 합계 검증
- 사번별 조회 전용·실무담당자·관리자 권한
- 실무담당자 확정 후 사업별 잠금

## 실행

```bash
npm install
npm run dev
```

브라우저에서 Vite가 표시하는 로컬 주소를 엽니다.

## 테스트 및 빌드

```bash
npm test -- --run
npm run build
```

## 프로토타입 로그인

초기 관리자 사번은 `admin`입니다. 프로토타입에서는 비밀번호 입력 여부만 확인합니다.

관리자는 사업관리 화면의 사용자 권한 지정에서 사번별 역할을 지정할 수 있습니다.

## 엑셀 업로드

투자비 가져오기에서 여러 `.xlsx` 또는 `.xls` 파일을 선택합니다. 하나의 사업에 여러 투자오더를 연결할 수 있으며, 파일별 월 실적투자비가 합산되어 누적투자비에 반영됩니다.

표준 보고서 형식은 다음 규칙을 사용합니다.

- B4: 오더/그룹 및 투자오더번호
- B5: 리포팅 기간
- C14: 월별 실적투자비
- C15:C108: 검증 합계 범위
- B109의 `* H,S`: 사용 범위 종료 표시

## 현재 저장 방식과 운영 전환

현재는 브라우저의 `localStorage`와 `sessionStorage`를 사용하는 시연용 구조입니다. 운영 전환 시 다음 항목을 회사 시스템 또는 서버 API로 교체해야 합니다.

- 사내 SSO·사번 인증
- 사용자 권한 및 사업 데이터 저장
- 투자오더번호 조회
- 투자비 파일 자동 수집
- 업로드·확정 이력과 감사 로그
